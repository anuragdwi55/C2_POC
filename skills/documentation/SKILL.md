# Documentation skill

1. Read `spec/requirements.md` and related spec files before documenting behavior.
2. Update `spec/api-contract.md` when endpoints change.
3. Update root `README.md` with run instructions (backend port 8080, frontend 3000).
4. Record significant prompts in `docs/prompt-history.md` and `.specstory/history/`.
5. Note any rejected AI suggestions under **AI review log** in `docs/prompt-history.md`.
